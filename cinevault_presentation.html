Product Overview & User Experience

The Platform: Problem, Solution & User Journey

Cinevault tackles the modern "streaming paralysis" phenomenon: infinite catalog choice leading to decision fatigue. Instead of endless vertical scrolling, it offers an intentional, mood-driven discovery path.

The Streaming Paralysis Problem Challenge
Users spend an average of 18 minutes browsing fragmented streaming apps without selecting a title. Standard algorithms recommend based on historical consumption rather than current state of mind, leading to abandoned viewing sessions.
The Cinevault Vibe Solution Resolution
Cinevault introduces a 6-question progressive onboarding funnel ("The Vibe Flow") that captures emotional posture, available runtime, social context, and aesthetic preferences to generate a tightly tailored Tonight's Shortlist in seconds.

The End-to-End User Experience

1. The Vibe Profiler Input
Visual poster tiles and interactive SVG clocks guide the user through format, mood, genres, runtime, audience, and era selections with intuitive single/multi-select rules.
2. Curated Shortlist Feed
Instant presentation of curated recommendations. Features rapid grid/list view toggles, category filtering (All, Movies, TV, Anime), and quick-action bookmarking.
3. Deep Inspection Detail
Full title page featuring high-res backdrops, trailer bottom-sheet modal, aggregated ratings (TMDb, IMDb, Rotten Tomatoes), cast details, user reviews, and direct provider links.

Core Functional Pillars

Pillar User-Facing Capability Engineering Implementation
Tonight Feed Dynamic feed of titles tailored to active vibe filters. Dual grid & list layouts with infinite scroll pagination. Dual-page concurrent fetch against TMDb discover endpoint with client-side deduplication and fallback caching.
Watchlist (wl) One-tap bookmarking to save titles for future evenings. Badged count in bottom navigation. Persisted in localStorage['cinevault_wl'] as serialized ID arrays; synchronized with mediaRegistry.

Algorithm & Discovery Engine

The 6-Step Vibe Profiling Engine

Rather than presenting complex search query forms, Cinevault structures user preference gathering through a curated 6-dimension funnel with clear constraints and real-time validation.

1
Format Selection (Target Media Paradigm)
Single-select choice: Feature Film (movie), Multi-Season TV (tv), Limited Series (mini), Anime & Animation (anime), or Real-World Documentary (doc). Switches the TMDb query target between /discover/movie and /discover/tv.
2
Emotional Mood (Affective State Mapping)
Pick up to 3 mood states: Brain-off Popcorn (comfort/comedy), Edge of Your Seat (suspense/thriller), Mind-Bending (sci-fi/cerebral), Dark & Gritty (noir/crime), Tearjerker (emotional drama), or Big Screen Blast (high-octane action).
3
Genre Refinement (Taxonomic Anchoring)
Multi-select pill tags spanning 18 standard cinematic categories (Action, Comedy, Drama, Sci-Fi, Horror, Romance, etc.). Injected into TMDb query as logical OR/AND combinations.
4
Available Runtime (Temporal Constraint)
Visualized with custom animated SVG clock dials: Quick Bite (≤90 min), Standard Feature (90–125 min), Epic Night (≥145 min), or No Preference. Translates directly to with_runtime.lte and with_runtime.gte parameters.
5
Audience & Demographic (Maturity Gating)
Contextual viewing groups: Kids (strictly G & PG animation/family), Family Night (PG-13 blockbusters), Date Night (PG-13/R romance and thrillers), or Solo Adults (unrestricted R & NC-17). Translates to US MPAA certification filters.
6
Era & Language (Aesthetic & Cultural Dimension)
Era pills (2024–2026 New Releases, 2010s Hits, 2000s Nostalgia, 90s Classics, Golden Age) combined with language preferences (English/Hollywood, Korean Cinema, Japanese, International Subtitled).

Validation & Funnel State Machine

Progressive Step Validation
Each screen defines min and max selection boundaries. The "Continue" CTA remains disabled until stepValid() confirms constraints are satisfied, preventing invalid search executions.
Summary & Curation Handoff
Upon completing Step 6, the user reaches the active vibe summary review displaying colored chips of all selected dimensions with options to "Open my feed" or "Reset feed".

Query Synthesis & Integration Engine

Query Synthesis & TMDb Integration Engine

Cinevault's proprietary query compiler translates subjective emotional states into high-precision TMDb v3 Discover API query strings while preserving high variety and preventing catalog dilution.

Query Compilation Logic: buildDiscoverUrl()

// Excerpt from Cinevault Query Engine (src/services/tmdb.ts)
export function buildDiscoverUrl(apiKey: string, filters: OnboardingFilters, page: number = 1) {
  let endpoint = filters.fmt?.has('tv') ? 'tv' : 'movie';
  const url = new URL(`https://api.themoviedb.org/3/discover/${endpoint}`);

  // Base Quality Guards
  url.searchParams.set('include_adult', 'false');
  url.searchParams.set('vote_count.gte', '20'); // Filter out low-sample noise
  url.searchParams.set('sort_by', 'popularity.desc');

  // Cross-Medium Taxonomy: TV vs Movie Genre Mapping
  // TMDb defines distinct IDs for TV (e.g. Action&Adventure: 10759, Sci-Fi&Fantasy: 10765)
  const gId = isTv ? (TV_GENRE_TO_TMDB_ID[genre] || GENRE_TO_TMDB_ID[genre]) : GENRE_TO_TMDB_ID[genre];

  // Animation Anchoring: Prevents live-action from swamping anime/cartoon queries
  if (wantsAnimation) {
    url.searchParams.set('with_genres', `16,${otherGenres.join('|')}`);
  }

  // Runtime Translation
  if (filters.time?.has('q')) url.searchParams.set('with_runtime.lte', '90');
  if (filters.time?.has('e')) url.searchParams.set('with_runtime.gte', '145');

  // Maturity / Certification
  if (filters.age?.has('kids')) url.searchParams.set('certification', 'G|PG');
  if (filters.age?.has('solo')) url.searchParams.set('certification', 'R|NC-17');

  return { url: url.toString(), headers, endpoint };
}

High-Density Concurrent Fetch Strategy

Standard TMDb API responses return 20 items per page. To provide users with a rich, immersive browsing catalog immediately upon completing their vibe profile, Cinevault issues two concurrent page requests (Page 1 + Page 2) simultaneously during initial feed load:

The Animation Anchoring Heuristic

The Risk: Live-Action Dilution Problem
When users select multiple moods alongside Anime/Animation, naive query builders concatenate all genre IDs with pipe delimiters (OR). This allows massive live-action hits to drown out animated works.
The Fix: Mandatory Genre Anchor Engine Solution
Cinevault isolates Genre ID 16 (Animation) as mandatory: with_genres=16,28|12. This guarantees that every returned result is animated while still satisfying mood criteria.

State Architecture & Persistence

State Architecture, Persistence & Lifecycle

Cinevault implements a centralized reactive state container via React Context API, segregating long-term persistent user records from high-frequency in-memory discovery feeds.

Persistent Tier (localStorage) Storage Backed
User collections that must survive browser reboots and sessions:
  • cinevault_wl: Set of bookmarked title IDs.
  • cinevault_wd: Set of watched title IDs.
  • cinevault_tmdb_key: Optional custom API key.
Transient Tier (React Context State) Memory Only
Session-scoped reactive state managed inside AppContext:
  • feedItems: Active curated media list.
  • sel: Active vibe filter selections.
  • cur: Active onboarding step pointer.
  • feedView: Grid vs List view toggle.

Detailed State Lifecycle & Feed Persistence Analysis

What Happens When a User Clicks Around & Returns? Lifecycle Insight
Navigation Inside the App: Because AppProvider sits at the root of the React tree outside HashRouter, navigating from /tonight to /title/:id and pressing Back does not unmount AppContext. The feed and selections stay intact in memory.

Why the Feed May Reset to Default Catalog:
  1. Hard Page Refresh (F5 / Reload): Because sel and feedItems are stored in React memory and not in localStorage, a hard reload resets sel to empty sets and re-initializes feedItems with the fallback catalog CURATED_MEDIA_CATALOG.
  2. Category / Sort Filter Triggers: Changing category tabs triggers loadFeed(). If vibe selections had not completed or an API error occurred, it gracefully falls back to the curated catalog.

Fault-Tolerance & Engineering Roadmap

Architected with dual-layer offline resiliency to guarantee zero user interruption, coupled with a forward-looking roadmap for AI embeddings and cross-device synchronization.

The Dual-Mode Resiliency Architecture

Live TMDb v3 Integration Mode Online
Full dynamic access to 800,000+ films and television series with live streaming provider availability, fresh trailers, and real-time community ratings.
Curated Offline Fallback Engine Fail-Safe
When offline, or if TMDb hits rate limits, getCuratedMedia() executes client-side filtering over CURATED_MEDIA_CATALOG, ensuring an uninterrupted demo experience.
